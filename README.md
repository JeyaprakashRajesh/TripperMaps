# TripperMaps

An iOS app that streams **Apple Maps** to the round **Royal Enfield Tripper Dash** on the
Himalayan 450. It keeps working with the phone locked, uses as little battery as possible, and
runs at up to 10–12 fps instead of the stock app's ~4 fps.

See **DESIGN.md** for the architecture, the fps and battery strategy, and the real projects this builds on.

> Unofficial hobby project. Not affiliated with Royal Enfield. Set up your route before you
> ride. Don't use the phone while riding.

## Build the .ipa on Windows (no Mac needed)

GitHub's hosted Macs do the compiling. You only need a browser and Git.

1. Create a GitHub repo (a **public** repo gets free macOS build minutes; a private repo uses up
   your minutes about 10× faster).
2. Push this folder to it:
   ```powershell
   cd "C:\Users\rjeya\Desktop\tripper dash"
   # one-time: move the CI workflow to where GitHub looks for it
   mkdir .github\workflows -Force; move ci\build-ipa.yml .github\workflows\
   git init
   git add .
   git commit -m "TripperMaps starter"
   git branch -M main
   git remote add origin https://github.com/<you>/TripperMaps.git
   git push -u origin main
   ```
3. Open the repo, go to **Actions**, then **Build unsigned IPA**. It starts on every push, or you can start it with **Run workflow**.
4. When it finishes (about 5–10 min), download the **TripperMaps-unsigned-ipa** artifact and unzip it to
   get `TripperMaps-unsigned.ipa`.

The project file is generated by **XcodeGen** from `project.yml`, so there is no `.xcodeproj` to
maintain by hand on Windows. To add a source file, drop it into `App/Sources/`.

## Install on your iPhone from Windows

**Sideloadly** (simplest)
1. Install **iTunes** and **iCloud** from Apple's website (*not* the Microsoft Store versions),
   then install Sideloadly from sideloadly.io.
2. Plug in the iPhone, open Sideloadly, drag in the `.ipa` and enter your Apple ID. Sideloadly
   signs the app with it.
3. On the iPhone, open **Settings → Privacy & Security → Developer Mode** and turn it on (the phone restarts). Then
   open **Settings → General → VPN & Device Management** and trust your Apple ID.

**Free Apple ID limits:** the app expires after **7 days**. Re-sign it with Sideloadly, or install
**SideStore** to refresh it on the phone itself. A paid Apple Developer account ($99/yr) gives
1-year signing and the Hotspot entitlement (auto-join of the bike's Wi-Fi).

## First ride

1. On the dash, set the screen type to **Digital** and open the phone-pairing screen. It shows the
   `RE_XXXX_XXXXXX` network.
2. On the iPhone, join that Wi-Fi once in **Settings → Wi-Fi**. It has no internet, so iOS makes
   mobile data the default route and your phone, Apple Maps and other apps stay online. The app
   pins its own dash traffic to the Wi-Fi interface (`requiredInterface`, cellular prohibited), so
   the two never mix. Keep **Mobile Data** on. With a free Apple ID the app can't
   auto-join (that needs the paid-only Hotspot Configuration entitlement), so this step stays manual.
3. Open TripperMaps, allow **Location** and **Local Network**, search for a destination, and wait for
   "Rendering Apple Maps tiles" to finish. You can then lock the phone.
4. Plug the phone into the bike's USB-C port on long rides. With charging on, **Turbo 12 fps**
   becomes available.

## Test without the bike

Test mode replaces the dash with your Windows PC. The iPhone streams the exact same H.264 video to
the PC, so you can check the Apple Maps rendering, smoothness, fps, bitrate and locked-phone
behaviour at your desk. The dash login (K1G) is skipped, so this works before that part is ported.

1. Put the PC and the iPhone on the **same Wi-Fi** (your home router).
2. On the PC: `winget install Gyan.FFmpeg`, then in PowerShell from this folder run
   `powershell -ExecutionPolicy Bypass -File tools\watch-dash.ps1`. It prints your PC's IP and
   opens a 526×300 player window. VLC also works: open `tools\dash-preview.sdp`.
   If the window stays black, allow UDP 5000 through Windows Firewall (the script prints the command).
3. In the app, under **Testing without the bike**:
   - **Test mode: stream to PC** on, and type the PC IP the script printed.
   - **Simulate ride** on (fake GPS at 10–100 km/h along the route, or a 400 m loop for a free ride).
4. Search a destination (or Free ride), wait for the tiles, and tap start. Allow **Local Network** when asked.
5. Check:
   - The PC window and the round preview in the app both show the heading-up Apple Map moving smoothly.
   - The stats show **Dash FPS ≈ 10**, about 400–650 kbps, and 0 missing tiles.
   - **Lock the phone**: the PC stream should keep going (a background-mode test).
   - Turn on Low Power Mode: the mode switches to **Eco 6 fps**.
   - Stop the simulated bike (speed 10 km/h, or sit still with simulate off): fps drops.

Optional: TripperDash++'s `tools/fake_dash` (Docker) emulates the dash's login and ports, for
testing the K1G code once it's ported.
